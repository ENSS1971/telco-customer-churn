# Contexto:

Este projeto faz parte do desafio para cientista de dados. O objetivo é criar um pipeline de dados
capaz de identificar clientes de uma empresa de telecomunicações que têm maior probabilidade de cancelar o
serviço (*churn*), fornecendo insumos para estratégias de retenção.


# Estrutura de Pastas
- 'data/raw/': Dados originais.
- 'data/processed': Dados limpos e prontos para modelagem.
- 'notebooks/': Análise Exploratórias e modelagem.
- 'src/': Códigos-fonte (.py) para o pipeline.
- 'moodels': Modelos treinados salvos.
- 'reports/': Relatório e registros de decisões técnicas.

## Ferramentas Utilizadas
- **Linguagem**: Python 3
- **Bibliotecas Principais**: pandas, scikit-learn, XGBoost, matplotlib, shap
